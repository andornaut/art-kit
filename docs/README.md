# Art Kit documentation

Art Kit provides shared build-time tools for pixel art, fonts, sprite sheets and atlases.

- [Guides](guides/README.md) walk through installing, upgrading, checking and releasing the kit.
- [Reference](reference/README.md) documents the public API, build runner and package requirements.
- [Design](design/README.md) explains the implementation and links to historical design proposals.
- [Work](work/README.md) indexes work records by design area and describes the work-file format.
