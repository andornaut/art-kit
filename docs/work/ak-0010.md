## Scope

Filter PNG rows into an open deflate stream instead of copying and filtering the whole image.

## Criteria

- `encodeRgbaPng` and `encodeRgbPng` filter each row from the caller's pixels in small batches and
  write one IDAT.
- Output stays byte-identical to pngjs 7.0.0, checked by a differential test.
- Deflate level 0 and inputs pngjs treats specially still go through pngjs.

## Decisions

- The image is no longer copied twice, so memory stays bounded for large sheets.

## Outcome

Shipped in 0.14.1 (69765bd).
