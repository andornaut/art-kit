## Outcome

Apply the shared [source-structure policy](https://github.com/andornaut/game-coordinator/blob/main/docs/game-policies.md#source-structure)
(gc-0029) to the kit, with no public interface or output change.

- ESLint guards the area layers in `node/src`: `raster` imports no other area, `codecs` imports
  `raster`, `atlas` imports `raster` and `codecs`, `fonts` imports `raster`, and `build` imports
  no other area.
- `import-x/no-cycle` covers `scripts/` and the tests as well as `node/src`.
- TypeScript `erasableSyntaxOnly` is on; parameter properties, enums and namespaces use erasable
  forms.
