## Scope

Shape drawing into RGBA buffers that matches Pillow `ImageDraw.Draw(image)`.

## Criteria

- Point, line, polygon, ellipse, arc, rectangle and rounded rectangle write ink directly.
- Node tests compare 3055 Pillow-generated cases exactly.

## Decisions

- `draw` uses the package `Rgba`, `Point` and inclusive `Bounds` types (b99e922).

## Outcome

Shipped in 0.12.0 (f901e56). Rounded rectangles and curve joints were removed in 0.22.0
([ak-0023](ak-0023.md)).
