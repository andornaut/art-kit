## Scope

Encode complete TrueType fonts to WOFF2 for download size reduction.

## Criteria

- `encodeWoff2(font)` encodes a static TrueType font with `glyf` and `loca` through the optional
  exact peer `wawoff2@2.0.1`.
- Signed (`DSIG`), CFF, collection and malformed inputs are rejected.
- Decoded output matches every glyph, metric, kerning, name and licence table of the Liberation Sans
  fixtures outside explicit serialization differences.

## Decisions

- No subsetting or fidelity options.
- The peer loads only when encoding, so other imports need neither it nor Skia.

## Outcome

Shipped in 0.26.0 (2411975).
