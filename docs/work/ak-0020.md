## Scope

Fail font rendering on characters missing from the font file.

## Criteria

- `rasteriseGlyphs` reads the Unicode cmap (format 12, else format 4) and throws `RangeError`
  listing every requested character the file lacks.
- `fontCoverage` exposes the mapped code points.

## Decisions

- Rejecting unmapped characters keeps Skia from drawing them from a system font.
- The cmap is read directly, without the fontkit peer removed in [ak-0014](ak-0014.md).

## Outcome

Shipped in 0.19.0 (c59e5b5).
