## Scope

Run a game's art build sets one at a time in dependency order.

## Criteria

- `buildOrder` runs each set after every set it needs, ties broken by declaration order; an unknown
  need or a cycle throws `RangeError`.
- Selected sets run with every set downstream of them.
- `check: { paths }` snapshots the files under the paths by SHA-256 before and after the rebuild and
  fails on any difference.
- `buildCommand` handles `[--check] [SET...]` with exit status 0, 1 or 2.

## Decisions

- The module uses only Node built-ins, and the check works without Git.
