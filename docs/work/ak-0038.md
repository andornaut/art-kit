## Scope

Catch stale build outputs without Git.

## Criteria

- Each set lists the paths it writes in `outputs`, and `check.static` lists hand-kept files.
- With `outputs: true` the check fails on any file under the check paths that no output or static
  entry claims, printed as `!\tpath`.
- Every set's outputs count on a partial rebuild, and nothing is deleted.

## Decisions

- Declared outputs, the option the user chose, catch a file a generator stopped writing.
