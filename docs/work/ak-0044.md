## Scope

Add `webp.decodeWebp(bytes)` so producers can check their lossy WebP output against their own
guards.

## Criteria

- Returns the RGBA image through the existing non-SIMD `@jsquash/webp@1.5.0` decoder, with no new
  dependency.
- Matches the pinned decoder, repeats exactly, returns independent copies and rejects bad input.

## Decisions

- Returns `RgbaImage` (`Uint8Array` data), the type the encoders take, so decoded output composes
  with the rest of the kit. AVIF and other shared decoding remain unapproved.

## Outcome

Shipped in 0.32.0.
