## Scope

Extend the work file convention to every user request, approved or not.

## Criteria

- The convention lists the `proposed` and `declined` statuses and a request reference.
- User requests that were not approved have their own work files.

## Decisions

- `status: done` is set in the commit that lands an item, so a release tag containing it marks the
  item deployed.

## Outcome

Landed with the convention change and ak-0043.
