## Scope

Export pixel frames as SVG with crisp edges and integer scaling, as a way to reduce download size.

## Criteria

- Same-colour pixels merge into shapes on an integer view box with crisp edges.
- A rendered SVG matches its source PNG at each integer scale.

## Decisions

- Estimated at one to one and a half weeks. Declined because the games' art is already vector or
  small raster; font subsetting (ak-0037) was approved instead.

## Outcome

Not built.
