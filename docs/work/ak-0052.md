## Outcome

Refactor `node/src` for project structure, encapsulation and simplification: clean module
interfaces, an acyclic import graph and pure functions where possible. Preserve every public
export path, exported name, signature and output. Any public interface change is a separate
proposal for user approval.

## Result

- Sources are grouped by area: `raster` (images, colour, frames, drawing and comparison),
  `codecs` (PNG, indexed PNG, GIF, ICO and WebP), `atlas` (atlas layout and build, sprite
  sheets), `fonts` (glyphs, bitmap fonts, WOFF2 and SFNT tables) and `build`. Export map targets
  follow the moved files; public specifiers, names, signatures and outputs are unchanged.
- `raster` re-exports its operations from `pixels`, `resample`, `filters` and `frames`, which
  share argument checks in `checks` and structural types in `types`. `build` keeps the runner,
  command line and process step; `sets` holds the set table logic without I/O and `snapshot` the
  snapshot check. `sfnt` owns the table directory, TrueType validation and reassembly that
  `cmap`, `fontNames` and `woff2` duplicated, and `cmap` no longer reads files.
- `fonts` and `woff2` share one missing-glyph error, both PNG encoders one IHDR writer, and
  `colour` one sRGB encoding transfer. The PNG predictor lives in its only user, and `draw`
  checks and truncates a box in one step, keeping its argument check order and error types.
- No cycles: `import-x/no-cycle` runs in `make lint`, and a one-off scan of every `node/src`
  import, type imports included, found none. Each public subpath reaches the same Node and
  external modules as before.
