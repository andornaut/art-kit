## Outcome

Enable `@typescript-eslint/no-import-type-side-effects` for the TypeScript sources, scripts and
container checks, so an import whose specifiers are all inline `type` must be written as
`import type`. Node type stripping keeps such an import and loads the module, which can close a
runtime cycle that `import-x/no-cycle` does not report. No published interface or output change.

## Decisions

- D1 (user, 2026-11-26; answers q-art-kit-14): Adopt (Recommended)

## Result

The rule runs on `node/src`, `scripts` and the container checks. A probe module with an inline
type-only import failed `make lint` with this rule; the committed tree has no such imports.
