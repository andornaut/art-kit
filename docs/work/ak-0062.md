## Scope

Measure one representative asset-build workload and improve an existing hot path while preserving
public contracts and exact output. Keep the current sprite-sheet renderer.

## Criteria

Compare baseline and candidate under the same conditions, verify output equality and run the
Art-kit package gate.

## Outcome

Indexed PNG encoding retains temporary palette indices and remaps them in place. This removes
a four-byte-per-pixel buffer on the successful encoding path. An isolated comparison of 18
fixtures over 15 paired timings measured 46.76 ms versus 33.09 ms per batch (28.0% median paired
reduction). Encoded PNG bytes and decoded pixels matched.
