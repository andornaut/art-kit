## Scope

Encode opaque images as RGB PNG beside the RGBA encoder.

## Criteria

- `png.encodeRgbPng(options, image)` takes the same compression options as `encodeRgbaPng`.
- Codec tests cover the RGB output.

## Decisions

- An opaque image drops the alpha channel instead of writing alpha 255.

## Outcome

Shipped in 0.11.0 (357e935).
