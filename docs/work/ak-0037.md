## Scope

Subset a font to the glyphs a set of strings uses and emit WOFF2.

## Criteria

- `subsetWoff2({ strings, label? }, font)` keeps only the code points of `strings` through HarfBuzz
  hb-subset, with the optional exact peer `harfbuzzjs@1.6.4`.
- It throws `RangeError` naming every character the font's cmap does not map.
- Layout, hinting, variation axes and licence names are kept.

## Decisions

- HarfBuzz is the subsetter (user, 2026-11-18).
- Failing on uncovered characters keeps the browser from falling back to another font.

## Outcome

Shipped in 0.30.0 (97bcb88). b8aadab states that subsets keep GPOS kerning but drop the legacy
`kern` table.
