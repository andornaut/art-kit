## Scope

Make and CI run every check through the shared stock-image core, with no Dockerfile.

## Criteria

- `tests/container/check-stock` runs `check`, `lint`, `test` or `build` in the stock images pinned
  in `tests/container/images`.
- The shared `tests/container/stock` functions copy the Git-listed source without Git metadata and
  run each container as uid 19001 with a read-only root and bounded CPU, memory and scratch.
- Each container starts only while the one-minute load is below 20.
- `make check` is the only check entry point (24da8a9).

## Decisions

- The `stock` library is copied verbatim, so every repository runs the same core.
- Source is copied into the containers with POSIX `cp` (7a69ff6).

## Outcome

Shipped in 0.23.0 (848a5ac, 24da8a9, 7a69ff6).
