## Scope

`scripts/container.mts` holds container orchestration behind thin shell wrappers.

## Criteria

- The module runs on host Node through type stripping and holds the load check, container policy,
  archive streaming, result copies and cleanup on every exit path.
- The shell scripts keep their usage and only check arguments.
- `node-package` is TypeScript.

## Decisions

- Each container step is an argument array run through `docker exec`.
