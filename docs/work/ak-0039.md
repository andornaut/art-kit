## Scope

Rename a subset font, as a SIL OFL Reserved Font Name requires.

## Criteria

- `names` replaces name IDs 1, 3, 4 and 6, 16 when present and 5 with `version`, in every Unicode,
  Windows and Mac Roman record.
- Copyright, licence and the other records stay unchanged, with valid table checksums.
- It throws `RangeError` when a replaced name or a subfamily contains a `reserved` name.

## Decisions

- Renaming is part of `subsetWoff2`, since only a modified font needs it.

## Outcome

Shipped in 0.31.0 (69e96db).
