## Scope

Throw `RangeError` on nonfinite drawing bounds or stroke widths before writing to the target.
Keep finite-coordinate rounding and output unchanged.

## Decisions

- D1 (user, 2026-11-26; answers q-art-kit-15): Throw RangeError (Recommended)

## Outcome

Boxed drawing operations validate bounds and all stroke operations validate widths before
writing pixels. Nonfinite input throws `RangeError`. Finite inputs retain the existing output.
