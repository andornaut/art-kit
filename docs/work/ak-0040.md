## Scope

Leave transparent pixels between atlas cells.

## Criteria

- `packAtlas` takes `padding` (default 0): transparent pixels between neighbouring cells on a shelf
  and between shelves, outside `extrude`, never at page edges.
- A padding that is not a non-negative safe integer throws `RangeError`.

## Decisions

- The default of 0 keeps existing atlases unchanged.
