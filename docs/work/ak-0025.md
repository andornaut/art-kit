## Scope

`make check`, `lint`, `test` and `build` run category checks in isolated containers, and native
package commands run the same checks without Docker.

## Criteria

- Explicit check category modes; lint type-checks and test forwards focused test flags.
- `scripts/native-check.mts` runs native lint, test and build, and `lint-node` omits ShellCheck and
  Markdown.
- Markdown validation runs once through the lint gate.
- Node tooling is 24.22.2.

## Decisions

- Markdown tool dependencies are patched with scoped locked overrides until upstream resolves
  patched versions.

## Outcome

Shipped in 0.23.0 (1d927a9, 8fd843c, 4b8e937). The container adapters were replaced by stock images
in [ak-0026](ak-0026.md).
