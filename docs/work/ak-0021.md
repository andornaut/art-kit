## Scope

Self-checks for build set tables, a process step and a Git index check mode.

## Criteria

- `strictOrder` and `modules` directory reconciliation, both off by default.
- `nodeBuild` runs a set in its own Node process.
- A sole `--help` or `-h` prints usage and exits 0.
- `check.index` also fails on files that differed from the Git index or were untracked before the
  run; the default check stays Git-free.

## Decisions

- Self-checks are opt-in, so tables built in process keep working.

Shipped in 0.20.0 (7678a19).
