## Scope

Lossy WebP encoding with every setting explicit, for download size reduction.

## Criteria

- `encodeLossyWebp` requires `quality` 0..100, `method` 0..6, `alphaQuality` 0..100 and boolean
  `exact`.
- It uses the pinned `@jsquash/webp` 1.5.0 encoder; the lossless function and its golden are
  unchanged.
- Decoded alpha is exact at `alphaQuality: 100`.

## Decisions

- No new dependency; AVIF and a shared decoder are not part of this item.

## Outcome

Shipped in 0.25.0 (670d2ff).
