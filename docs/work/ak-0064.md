## Scope

Group related implementation files behind clear interfaces. Prefer cohesive directories and
consistent file roles. Identify concrete friction in the public API.

## Criteria

Preserve public entry points, contracts, output and existing layer checks. Propose any public
interface change separately. Run the isolated package gate.

## Outcome

`build/draw` keeps its public entry and delegates scan conversion, ellipse and arc clipping,
pixel writes and rounding to private modules. The drawing implementation can depend on only
its own modules and the parent image and geometry types. Existing declarations are identical.
The package gate and a 12,000-call comparison verified identical pixels and errors.
