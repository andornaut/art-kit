# art-kit

Shared TypeScript tools for scripted pixel art, image and font processing, sprite sheets, atlases,
and asset builds. Art-kit ships as the ESM package `@andornaut/art-kit` through GitHub Releases.
Source lives in `node/src` under `raster`, `codecs`, `atlas`, `fonts` and `build`.

Browse the [documentation](docs/README.md), [design areas](docs/design/README.md), or
[work items](docs/work/README.md).
